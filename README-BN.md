# Golden Flower AI Signal — প্রাথমিক সংস্করণ

এটি একটি **ম্যানুয়াল রাউন্ড-লগ ও পরিসংখ্যান ডেমো**। এটি Poppo Live-এর স্ক্রিন নিজে থেকে পড়ে না, বেট করে না, এবং পরবর্তী বিজয়ী নির্ভরযোগ্যভাবে অনুমান করে না।

## APK তৈরির সহজ পথ
1. GitHub-এ নতুন repository তৈরি করুন।
2. এই ZIP-এর সব ফাইল ও ফোল্ডার repository-তে আপলোড করে `main` branch-এ commit করুন।
3. GitHub-এর **Actions** ট্যাবে `Build Android APK` workflow চালান (অথবা push-এর পর শেষ হওয়া workflow খুলুন)।
4. সফল হলে workflow-এর **Artifacts** অংশ থেকে `GoldenFlowerAI-debug-apk` ডাউনলোড করুন।
5. ZIP খুলে `app-debug.apk` Android ফোনে ইনস্টল করুন।

## সীমাবদ্ধতা
- এই ডেমোতে A/B/C-এর Pot এবং ফলাফল ব্যবহারকারী নিজে লিখবেন।
- ডেটা আপাতত অ্যাপ চলাকালীন মেমরিতে থাকে; অ্যাপ বন্ধ করলে মুছে যায়।
- ৩০টির কম রেকর্ডে কোনো হার-ভিত্তিক শীর্ষ অপশন দেখায় না।
- পরিসংখ্যান অতীতের ফলাফল বর্ণনা করে; র‍্যান্ডম গেমের ভবিষ্যৎ ফল নিশ্চিত করে না।
- এটি APK তৈরির জন্য GitHub Actions workflow-সহ সোর্স প্রজেক্ট; APK নিজে থেকে এখানে তৈরি/পরীক্ষিত নয়।
